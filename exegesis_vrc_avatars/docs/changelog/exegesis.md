# Changelog: Exegesis

All notable changes to the full Exegesis package (`exegesis-vX.Y.Z` releases, everything in
`Assets/_exegesis/`) are documented here. Props changes go in [props.md](props.md) *and* here,

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html). The release
workflow copies a version's section into its GitHub release; see [releasing.md](../releasing.md).
