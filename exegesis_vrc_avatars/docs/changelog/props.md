# Changelog: props

All notable changes to the props package (`props-vX.Y.Z` releases) are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this
project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html). The release
workflow copies a version's section into its GitHub release; see [releasing.md](../releasing.md).

## [Unreleased]

### Added
- TheCodeWarrior's PS1 Poiyomi module is now bundled in the package (`Assets/Editor/Poi_PS1/`).

### Changed
- The screwdriver material moved to Poiyomi 11 Toon.
- Requirements: Poiyomi 11.0.27, VRCFury 1.1437, VRChat Avatars SDK 3.10.6.
- Packages are now built and released automatically from tags.

## [1.1.1] - 2026-10-15

### Changed
- Requirements: Poiyomi 10.0.25, VRCFury 1.1429.0.

## [1.1.0] - 2026-02-11

### Added
- The screwdriver and the evil screwdriver (SPS), with a `screwdriver` contact sender and a
  `Tools/` expressions sub-menu.
